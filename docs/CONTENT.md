# Content, modules and media

## Copy and localization

Edit `src/content/en.json` and `el.json` for approved section headlines, paragraphs and lists. Edit `src/content/ui.js` for navigation, labels, errors, confirmations, project notices and all interface copy. Edit `src/content/legal.js` for bilingual reviewed policy text. Keep both locales in sync: checks reject missing section titles or mismatched UI keys. Copyright year, office details and creator credit live in `src/data/site-config.js`. The approved year stays 2026.

## Module registry

`src/data/site-config.js` controls the `modules` sequence. `src/components/registry.js` maps names to render functions:

| ID | Renderer | Purpose |
|---|---|---|
| hero | hero.js | Brand, poster/video, opening links |
| philosophy | editorial.js | Beyond the asset |
| expertise | editorial.js | Six accessible disclosures |
| destinations | galleries.js | Four documentary locations |
| ventures | galleries.js | Explicitly illustrative gallery and media viewer |
| lifecycle | editorial.js | Seven steps |
| team | editorial.js | Network expertise |
| partnerships | editorial.js | Collaboration and eligibility-qualified funding |
| contact | contact.js | Exactly three visible fields, direct links |

Reorder the sequence without changing the compiler. For a new module, add a renderer to the registry, bilingual content with title/paragraphs/items and its key to the sequence. Update section numbering/navigation if the narrative changes. Required contact and hero modules must remain for this specification. `shared.js` escapes copy and generates responsive media. Module HTML is emitted at build time and remains readable without JavaScript.

## Projects

Edit `src/data/projects.js`; schema is `src/data/schema.d.ts`. Each record has identity, localized title/location/description, type, stage, availability, publication rights, verified flag, media ID and optional video ID. Current records are `concept`, `not-offered`, `verified:false`. Never set verified or availability without written owner evidence. The initial renderer intentionally labels all cards illustrative; introducing real projects requires reviewing the renderer's status display, verified supporting documentation and owner permission, not just changing a flag.

Project image files use `public/multimedia/architecture/{media}-640.webp`, `-1200.webp`, `-1672.webp` and `{media}.jpg`; bilingual alt text is in `src/data/media.js`. Optional clips use `{video}.mp4`, with an image poster. Replace an image by updating these files and provenance, or add a new ID to the catalog. Generic hero/lifecycle IDs are `villa` and `hospitality`. No copyrighted image hotlinking. Image paths are centrally predictable; crop styling belongs in CSS.

Destinations follow `docs/destination-sources.json`, used by both cards and the public credits pages. Preserve original artist, source and license, and license derivatives of CC BY-SA photos accordingly. Change alt text and location evidence when replacing a photograph. Do not substitute fictional locations for documentary photography.

## Motion and video

`src/motion/index.js` implements reveal, hero parallax, pointer light and video controls without a runtime animation dependency. CSS handles opacity, transforms and blur. No scroll interception, shaders or custom cursor. Reduced motion and Save-Data prevent automatic video loading; mobile defaults to stills with explicit play. The pause-page-motion control pauses continuous effects. Film is an FFmpeg camera push over a generated still, **not generated moving scenery or an actual property recording**. No audio or captions required for this decorative loop. Target budgets: hero WebP <450KB, film <2MB, all runtime JavaScript <55KB raw. Production performance must be measured in a browser.

For future true image-to-video production: use the original villa render, a 10-second subtle stabilized forward dolly, unchanged architecture and geometry, no added people/signage, warm late-afternoon light, physically plausible pool reflections, no morphing, repeatable first/last framing, silent H.264 1280×720 ≤2MB with a matching poster. No video-generation tool was available; the delivered camera-move loop is the documented fallback.

## Design

`tokens.css` owns colors, spacing and fonts; `global.css` owns element defaults; `components.css` owns layouts and breakpoints. System Helvetica/Arial and Georgia avoid font downloads and support Greek. Header, language menu, navigation and contact remain keyboard-accessible; native details/dialog provide browser semantics.

## Future CMS

Export the same locale JSON, site settings and project schema at build time. Validate publication rights/status before exporting. Keep the browser bundle free of CMS administrative credentials; compile published content to static HTML. Future project detail pages can be generated by the same Node compiler with localized canonical routes and media records.
